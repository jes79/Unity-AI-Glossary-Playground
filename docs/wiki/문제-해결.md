# 문제 해결

| 증상 | 원인과 해결 |
| --- | --- |
| 한글이 □로 보임 | `Tools › Glossary › Setup Korean Font` 실행. Windows 외 환경이면 한글 TTF를 `Assets/06_Fonts/malgun.ttf`로 넣고 다시 실행 |
| 허브에서 "씬 없음" | `Tools › Glossary › Build All Scenes` 또는 `Refresh Build Settings` 실행 |
| `Input.GetKey` 관련 InvalidOperationException | 프로젝트는 New Input System 전용. `Keyboard.current` / `DemoInput` 사용 |
| 머티리얼이 분홍색 | `Tools › Glossary › Validate All Scenes`로 어떤 씬인지 확인 후 해당 씬 다시 빌드 |
| 0520 이후 다른 씬 그래픽이 이상함 | 0520은 씬에 있는 동안만 렌더 파이프라인을 바꿉니다. 비정상 종료 시 Project Settings › Quality의 Render Pipeline을 `PC_RPAsset`으로 되돌리기 |
| 1004 / 1012 이후 그림자·배칭 설정이 바뀜 | Play 중 URP 에셋 값을 바꾸고 종료 시 복원합니다. 강제 종료 시 `Assets/Settings/PC_RPAsset`을 git으로 되돌리기 |
| 1016 Atlas 차이가 안 보임 | Project Settings › Editor › Sprite Packer Mode가 "Sprite Atlas V1 - Always Enabled"인지 확인 |
| 0816 게임/결과 씬으로 안 넘어감 | `Refresh Build Settings` 실행(보조 씬 `0816_SceneManagement_*`가 자동 등록됨) |
