### 0302

**State / Transition** — 상태와 상태 사이 전환

> 요청 예문: "Run에서 Jump로 바로 넘어가게 Transition의 Has Exit Time을 끄는 법 알려줘."

- 씬: `Assets/00_Scenes/03_Animation/0302_StateTransition.unity`
- 핵심 스크립트: `StateTransitionDemo`
- 빌더: `Assets/01_Scripts/Editor/Scenes/03_Animation/Build0302_StateTransition.cs`
- 구현 방식: 런타임 데모
- 개념: 상태와 상태를 잇는 화살표. 조건(Condition), 전환 시간(Duration), 현재 클립을 끝까지 재생할지(Has Exit Time)를 정한다. Has Exit Time 을 켠 채로 두면 입력이 늦게 반응하는 흔한 원인이 된다.
- 씬에서 보여 주는 것: Run→Jump 전환의 Has Exit Time ON/OFF 반응 지연 비교
- 확인 포인트: Run 중에 Space 를 눌러 보세요. Has Exit Time 을 켜면 현재 클립이 끝날 때까지 기다려 점프가 늦게 나가고, 끄면 즉시 전환됩니다. 두 Animator 를 나란히 비교할 수 있습니다.
