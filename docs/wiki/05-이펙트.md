### 0502

**Emission (Rate / Burst)** — 계속 뿜기 / 한 번에 터뜨리기

> 요청 예문: "피격 시 Burst로 파편 20개를 한 번에 뿌려줘."

- 씬: `Assets/00_Scenes/05_Effects/0502_EmissionRateBurst.unity`
- 핵심 스크립트: `EmissionDemo`
- 빌더: `Assets/01_Scripts/Editor/Scenes/05_Effects/Build0502_EmissionRateBurst.cs`
- 구현 방식: 런타임 데모
- 개념: Rate over Time 은 초당 몇 개를 계속 뿜을지, Burst 는 특정 시점에 몇 개를 한꺼번에 터뜨릴지를 정하는 설정. 분수·연기는 Rate, 타격·폭발은 Burst 가 맞다.
- 씬에서 보여 주는 것: Rate over Time 분수 vs 피격 시 Burst 파편 20개
- 확인 포인트: 왼쪽 분수(Rate)는 입자가 끊기지 않고 계속 나오고, 피격 시 오른쪽은 파편 20개가 한 번에 터지는지 보세요. Rate 를 0 으로 해도 Burst 는 작동합니다.
