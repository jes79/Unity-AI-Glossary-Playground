# 시작하기

## 1. 준비물

- Unity Hub + **Unity 6000.6.4f1** (다른 6000.x 버전도 열리지만 패키지가 업데이트될 수 있습니다)
- Windows 권장: 한글 폰트를 Windows의 맑은 고딕에서 만들어 씁니다.

## 2. 받기와 열기

```bash
git clone https://github.com/jes79/Unity-AI-Glossary-Playground.git
```

Unity Hub → **Add** → `Unity-AI-Glossary-Playground/Unity-AI-Glossary-Playground` 폴더를 고릅니다(바깥 폴더가 아니라 안쪽 폴더).
처음 열 때 패키지 임포트로 몇 분 걸립니다.

## 3. 씬 만들기

저장소에는 씬이 들어 있지만, 처음 한 번은 메뉴 **Tools › Glossary › Build All Scenes** 를 실행하세요.

- 한글 TMP 폰트(`Resources/Fonts/GlossaryFont`)를 만듭니다. 폰트 원본 `malgun.ttf`는 라이선스 문제로 저장소에 없고 이때 복사됩니다.
- 182개 씬과 생성 에셋(머티리얼·텍스처·사운드·애니메이션)을 다시 만들고 Build Settings에 등록합니다.

## 4. 둘러보기

1. `Assets/00_Scenes/0000_Hub.unity`를 열고 Play
2. 왼쪽에서 분야, 오른쪽에서 용어를 누르면 그 씬으로 이동
3. 씬 왼쪽 위 **정보 패널**에서 용어 설명, 요청 예문, 조작법, 실시간 상태를 확인
4. `F1` 패널 접기 · `[허브]` 목록으로 돌아가기

대부분의 씬에는 **비교 토글**(예: 코요테 타임 ON/OFF)이 있습니다. 끄고 켜면서 차이를 느껴 보세요.

## 5. 코드 읽는 법

| 보고 싶은 것 | 위치 |
| --- | --- |
| 기능 로직 | `Assets/01_Scripts/{분야}/` (네임스페이스 `GlossaryDemo.*`) |
| 씬 구성 방법 | `Assets/01_Scripts/Editor/Scenes/{분야}/Build{id}_{Name}.cs` |
| 셰이더 | `Assets/02_Shaders/{분야}/` |
| 용어 전체 목록 | `Assets/01_Scripts/Common/GlossaryCatalog.Data.cs` |

Inspector에 노출된 값(`[SerializeField]`, `[Range]`)을 Play 중에 바꿔 보는 것이 가장 빠른 학습법입니다.
