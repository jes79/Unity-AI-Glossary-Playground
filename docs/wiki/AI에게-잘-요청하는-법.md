# AI에게 잘 요청하는 법

AI에게는 "멋있게 해줘" 대신 **정확한 기능 이름 + 조건 + 내 환경**을 함께 말하면 한 번에 원하는 결과가 나옵니다.
각 분야 페이지에서 용어를 찾고, 요청 예문을 내 게임에 맞게 고쳐 쓰세요.

## 좋은 요청의 4요소

1. **대상**: 무엇에 적용하나 (플레이어, 적, 버튼, 총알…)
2. **기능 용어**: 이 위키의 용어 (예: 디졸브, 코요테 타임, 오브젝트 풀링)
3. **조건·수치**: 언제, 얼마나 (예: 체력 30% 이하일 때, 0.5초 동안, 속도 5)
4. **내 환경**: Unity 버전, 2D/3D, 렌더 파이프라인(URP/Built-in/HDRP), 입력 방식(New Input System/구 Input Manager)

| | 예시 |
| --- | --- |
| 나쁜 요청 | "적이 죽으면 멋지게 사라지게 해줘" |
| 좋은 요청 | "Unity 6, URP 3D 프로젝트야. 적이 죽으면 디졸브 셰이더로 1초 동안 아래에서 위로 사라지게 해줘. 경계선은 주황색으로 빛나게(Emission) 하고, Shader Graph로 만드는 방법과 C#에서 값을 조절하는 스크립트를 같이 알려줘." |

이 프로젝트의 씬 `0410_Dissolve`가 바로 이 요청의 결과물입니다.

## 결과가 마음에 안 들 때 다시 묻는 법

| 상황 | 이렇게 다시 요청하세요 |
| --- | --- |
| 에러가 남 | "이 에러가 나: [Console 에러 전문 붙여넣기]. 어느 줄이 문제고 어떻게 고쳐?" |
| 아무 반응이 없음 | "에러는 없는데 동작을 안 해. 확인해야 할 체크리스트(컴포넌트, 레이어, 태그, Inspector 연결)를 알려줘." |
| 머티리얼이 분홍색 | "셰이더가 분홍색으로 나와. 내 파이프라인은 [URP]야. 맞는 셰이더로 바꿔줘." |
| 코드가 너무 어려움 | "초보자용으로 다시 설명해줘. 줄마다 주석을 달아줘." |
| 기존 코드와 안 맞음 | "내 현재 스크립트야: [코드 붙여넣기]. 여기에 이 기능을 추가하는 방식으로 고쳐줘." |
| 느낌이 별로 | "조절 가능한 값(속도, 시간, 강도)을 Inspector에 노출해서 내가 직접 튜닝할 수 있게 해줘." |
| 용어를 모를 때 | "[슈퍼마리오처럼 점프 후 착지 직전 버튼을 눌러도 점프되는 것]을 게임 개발에서 뭐라고 불러? 그걸로 구현해줘." |

마지막 줄이 핵심입니다. 용어를 몰라도 참고 게임과 원하는 느낌을 설명하고 "이걸 뭐라고 불러?"라고 물으면, AI가 용어를 알려주고 바로 구현까지 이어갑니다.
