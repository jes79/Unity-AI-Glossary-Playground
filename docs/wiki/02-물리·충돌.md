## 항목별 상세

### 0201

**Collider** — 충돌 모양 (Box, Sphere, Capsule, Mesh)

> 요청 예문: "총알에 SphereCollider를 달고 벽에 맞으면 사라지게 해줘."

- 씬: `Assets/00_Scenes/02_Physics/0201_Collider.unity`
- 핵심 스크립트: `ColliderShooter, ColliderBullet`
- 빌더: `Assets/01_Scripts/Editor/Scenes/02_Physics/Build0201_Collider.cs`
- 구현 방식: 런타임 데모
- 개념: 물체의 충돌 모양을 정하는 컴포넌트. 실제 보이는 메시와 별개여서, 복잡한 모델에도 Box·Sphere·Capsule 같은 단순한 모양을 씌우는 게 성능상 유리하다. MeshCollider 는 정확하지만 비싸다.
- 씬에서 보여 주는 것: SphereCollider 총알이 벽에 맞으면 사라짐, Collider 종류 비교
- 확인 포인트: 마우스 왼쪽 클릭으로 총알을 쏘고 V 로 Collider 모양을 켜 보세요. 링(MeshCollider)의 구멍은 총알이 통과하는데, 석상은 생긴 모양이 아니라 캡슐 기준으로 맞습니다.

### 0202

**Trigger (Is Trigger)** — 통과는 되지만 '닿았다'만 감지

> 요청 예문: "코인을 Trigger로 만들고 OnTriggerEnter에서 점수 +10 해줘."

- 씬: `Assets/00_Scenes/02_Physics/0202_Trigger.unity`
- 핵심 스크립트: `CoinCollector`
- 빌더: `Assets/01_Scripts/Editor/Scenes/02_Physics/Build0202_Trigger.cs`
- 구현 방식: 런타임 데모
- 개념: Is Trigger 를 켠 Collider. 물체를 막지 않고 통과시키면서 닿았다는 사실만 알려 준다. 아이템 획득, 구역 진입, 함정 감지처럼 물리적으로 밀 필요 없는 판정에 쓴다.
- 씬에서 보여 주는 것: Trigger 코인 OnTriggerEnter로 점수 +10, Is Trigger 끄기 비교
- 확인 포인트: WASD 로 코인을 지나가 보세요. Trigger 가 켜져 있으면 통과하면서 점수가 +10 되고, T 로 끄면 코인이 벽처럼 막히고 점수는 오르지 않습니다.

### 0214

**터널링 / Continuous 충돌** — 빠른 물체가 벽을 뚫고 지나가는 현상 / 해결 설정

> 요청 예문: "빠른 총알이 벽을 뚫고 지나가. Continuous Collision Detection으로 고쳐줘."

- 씬: `Assets/00_Scenes/02_Physics/0214_TunnelingCCD.unity`
- 핵심 스크립트: `TunnelingDemo, TunnelingBullet`
- 빌더: `Assets/01_Scripts/Editor/Scenes/02_Physics/Build0214_TunnelingCCD.cs`
- 구현 방식: 런타임 데모
- 개념: 빠른 물체가 한 프레임에 벽을 지나쳐 충돌을 놓치는 현상(터널링)과, Collision Detection 을 Continuous 로 바꿔 이동 경로 전체를 검사하게 하는 해결책. 총알·빠른 투사체에서 자주 문제가 된다.
